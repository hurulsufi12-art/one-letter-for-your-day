# One Letter for Your Day

Exactly one letter, standing for the word that describes the day.

> U

U — for a day that went **unhinged**: vivid, funny at first read, and true
to a real chaotic day. A rare initial, so the word behind it lands at once.

`main.py` (Python 3.13, stdlib only) writes that letter to `/output/entry.txt`. Deterministic: the same letter on every run.
